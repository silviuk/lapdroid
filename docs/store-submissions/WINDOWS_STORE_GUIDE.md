# Microsoft Store submission for Lapdroid

The Store product is **Lapdroid**, ID **9N1L1QZJNT6Z**, using an MSIX package of the published x64 Windows executable. The Windows package does not include Android.

See [Store automation](../../store/AUTOMATION.md) for the GitHub Actions workflow, verified release packaging, required publisher secrets and safe API submission.

The first submission is prepared in Partner Center with free worldwide pricing, Utilities & tools category, English listing, functional Windows screenshots, [privacy policy](../../PRIVACY.md), and IARC age ratings. A reservation or draft does not mean the product is live. Check Partner Center for certification and publishing status.

The MSIX route lets the Store sign and host the package. Do not submit the unsigned NSIS installer through the EXE/MSI route. Certification timing is determined by Microsoft.
